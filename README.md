# Pagefold

Edição do [Pluck](https://github.com/LimaEdu-7x/pluck) para a Chrome Web Store. Salva a página aberta para ver offline, em ZIP ou num único arquivo HTML. Tudo acontece no seu navegador: nada é enviado a servidores.

## O que a Pagefold faz

- **Esta página:** HTML, estilos, fontes e imagens num ZIP para abrir sem internet.
- **Só HTML:** um arquivo .html leve (imagens e vídeos continuam no site).
- **Somente imagens:** imagens e vetores SVG em pastas separadas.
- **Automático:** recarrega e rola a página para carregar o conteúdo sob demanda (inclui rolagem infinita).

Permissões: painel lateral, aba ativa, abas, execução de script e downloads. O acesso aos sites é **opcional** e só é pedido no primeiro clique em arquivar. Não usa o depurador do navegador.

## Edição completa

Cópia fiel pelo Chrome DevTools Protocol (Modo Fiel), Site inteiro, Gravação manual e download de vídeo e áudio estão no [Pluck](https://github.com/LimaEdu-7x/pluck) (branch `main`), instalado em modo de desenvolvedor ("Carregar sem compactação").
